## Project Description

This project contains my laboratory activities for Web Systems and Technologies from Week 1 to Week 7. It includes HTML, semantic HTML and multimedia, CSS, JavaScript and DOM, Bootstrap, APIs and browser storage, and a mini full-stack starter project.

The project shows my progress in learning how to create, design, and improve webpages using different web development technologies.

## Weekly Laboratory Activities

### Week 1 –

 HTML Fundamentals

For Week 1, I learned the basic structure of HTML webpages. I practiced using HTML elements such as headings, paragraphs, and other basic tags. I also created and edited my webpage using Visual Studio Code.

### Week 2 – Semantic HTML and Multimedia

For Week 2, I learned how to use semantic HTML elements such as header, navigation, sections, and footer. I also learned how to add multimedia such as images and videos to a webpage.

### Week 3 – CSS Basics

For Week 3, I learned how to use CSS to improve the appearance and layout of a webpage. I practiced changing colors, fonts, spacing, buttons, navigation, and other design elements. I also applied my JD WebWorks theme to the webpage.

### Week 4 – JavaScript Basics and DOM

For Week 4, I learned how JavaScript can make webpages interactive. I worked with features such as displaying the current time, switching themes, adding tasks, handling forms, and using the DOM to change webpage content.

### Week 5 – JavaScript and Bootstrap

For Week 5, I learned how to use Bootstrap to create a modern and responsive webpage. I worked with Bootstrap components such as a responsive navbar, carousel, grid system, cards, and footer. I also improved the overall design of the webpage.

### Week 6 – API, Client, and Storage

For Week 6, I worked with browser storage and APIs. I created features involving Local Storage, user preferences, a Weather API, and a GitHub API. I also learned how to troubleshoot API errors and successfully make the Weather API work.

### Week 7 – Mini Full-Stack Starter

For Week 7, I worked on the mini full-stack starter project. This activity helped me apply the web development concepts I learned from the previous laboratory activities and work with a more complete web project.
